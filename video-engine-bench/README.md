# Video-engine benchmark: Remotion vs HyperFrames vs FFrames

The same 60-second Reason demo ([SCRIPT.md](SCRIPT.md)) built by three parallel Reason
Sessions, one per engine, under the rules in [PROTOCOL.md](PROTOCOL.md). All three use
the identical soundtrack from [make_score.py](make_score.py).

```bash
python3 make_score.py soundtrack.wav   # stdlib only, ~16 s, deterministic
```

Results are recorded in [RESULTS.md](RESULTS.md) once the runs finish.
